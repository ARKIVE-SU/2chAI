# Стол Мастера

Демонстратор технологий ролевого стола. Каждый пиксель кадра считает C++,
скомпилированный в WebAssembly. JavaScript передаёт касания и копирует кадр в canvas.

Откройте `index.html` в Chrome или Safari, на телефоне или на компьютере. Сервер не нужен,
wasm вшит в страницу.

## Управление

- Касание клетки: герой идёт туда (A*).
- Касание врага: герой подходит и бросает атаку d20 (11+ попадание, 20 крит).
- Перетаскивание: сдвиг карты. Два пальца или колесо мыши: масштаб.
- Кнопки: d20, туман войны, фонарь героя, новая карта, список технологий.

## Что внутри (`src/table.cpp`)

- C++17 → wasm32 голым clang, без Emscripten и стандартной библиотеки.
- Софтверный рендер: процедурные плиты, кирпич, стол, золотая рамка, тональная кривая ACES.
- Динамический свет: факелы и цветные кристаллы, тени через проверку видимости лучом DDA.
- Туман войны с «памятью» изученных мест.
- Процедурное подземелье из зерна: комнаты, коридоры, колонны, враги.
- 3D-кость d20: физика, кватернионы, укладка на грань, цифры на гранях (противоположные дают 21).
- Частицы: искры факелов и кристаллов, вспышки попаданий.

## Сборка

```sh
./build.sh   # нужен clang с целью wasm32 и wasm-ld
```

Скрипт собирает `build/table.wasm` и вшивает его в `index.html` из шаблона `web/index.html`.
