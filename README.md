# Сказ о /ai/ — двач-клип

Музыкальный клип об истории раздела /ai/ («Искусственный интеллект») на дваче.
Дед-олд рассказывает внукам-ньюфагам, как всё начиналось: первые треды
генерации в /b/ в 2022 году, кривые руки, проклятие аватарок, копродеды,
война с рисоваками, исход в /ai/ и нынешнее величие раздела.

Жанр клипа — SlopCore: музыка и видео собираются кодом и агентами.

## Этапы

1. **Лор** — сбор истории, персонажей, цитат и картинок. *Идёт.*
2. **Текст песни** — по актам, с хуками из лора.
3. **Музыка** — промпт для генератора, сборка частей.
4. **Клип** — мультик и код-анимация.

## Структура

- `lore/LORE.md` — библия лора: хронология, акты, пантеон персонажей, девизы и фразочки, открытые вопросы.
- `images/` — картинки из шапок тредов по эпохам, индекс в `images/INDEX.md`.

## Правила

- В песне и мультике только бордовые ники и маскоты, никаких реальных имён.
- Без наготы и без сексуализации персонажей, похожих на детей.
- Картинки — генерации анонов из архивов тредов. Источник каждой указан в индексе.
